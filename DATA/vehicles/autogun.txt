# the next area governs vehicle type groupings
# each autogun can target up to three groupings of vehicles
# the first group is chosen over the 2nd and 3rd
# any group of vehicle types can be chosen
# the format is:
#
# group #
# spec1
# spec2
# spec3
# 
# etc
# where # is a group number that is used for the actual autogun line itself
# and spec is the category/class text string for the vehicle type
# for example, an opel blitz is category GV_ and a class of truck
# thus the text string would be 
#
# GV_,truck
#
# the comma between the two is necessary

# the way the angle off mult and the degrees off mult work are as follows:,,
#,,
# Each second the gun sees/shoots at a target, the error cone shrinks by a certain amount, controlled by the time-to-min-cone field.
#,,
# The angle off mult is the *SPEED* in m/s that the target must be moving perpendicular to the gun,,
# in order to exactly cancel out the normal cone shrink.,,
#,,
# The degrees off mult is the number of *degrees* the gun must be off of target to exactly cancel the normal,,,,,,,,,,,,,,,,,,,
# shrink rate.,,,,,,,,,,,,,,,,,,,
#,,,,,,,,,,,,,,,,,,,
# Both are linear.  Thus, an angle off of 2x the degrees-off mult causes the cone to grow at the normal rate,,,,,,,,,,,,,,,,,,
# instead of shrinking at the normal rate.  An angle off of 1/2 the degrees-off-mult causes the cone to shrink,,,,,,,,,,,,,,,,,,,
# at half rate.,,,,,,,,,,,,,,,,,,,
#,,,,,,,,,,,,,,,,,,,
#,,,,,,,,,,,,,,,,,,,
# additional track degrees is the # of degrees past the field of fire that an autogun will track targets,,,,,,,,,,,,,,,,,,,

# autogun lines are as follows:,,,,,,,,,,,,,,,,,,,
#,,,,,,,,,,,,,,,,,,,
